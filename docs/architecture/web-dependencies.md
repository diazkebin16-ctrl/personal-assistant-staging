# Web dependency review

All packages are exact-version locked by `package-lock.json`; production loads no CDN script or
remote asset. “Active” means the selected release was current and available from the npm registry at
Phase 12 certification. Runtime bundle impact is the measured production bundle; dev-only packages
ship no browser code.

| Dependency                                                                                                   | Purpose / why required                              | Alternative considered                                         | License    | Status | Security and bundle impact                                          |
| ------------------------------------------------------------------------------------------------------------ | --------------------------------------------------- | -------------------------------------------------------------- | ---------- | ------ | ------------------------------------------------------------------- |
| `react`, `react-dom`                                                                                         | Semantic component UI and DOM rendering             | Vanilla DOM would duplicate lifecycle/state machinery          | MIT        | Active | Main UI runtime; included in the 123.34 KiB gzip JS bundle          |
| `@supabase/supabase-js`                                                                                      | Official Phase 1 browser authentication and refresh | Custom auth REST would duplicate security-sensitive authority  | MIT        | Active | Public-client only; largest non-React runtime share; no persistence |
| `typescript`                                                                                                 | Strict contracts and browser/server type checking   | JavaScript cannot enforce the required compile gate            | Apache-2.0 | Active | Dev only                                                            |
| `vite`, `@vitejs/plugin-react`                                                                               | Minimal deterministic SPA build and React transform | A meta-framework adds session/server surface without need      | MIT        | Active | Dev/build only; no runtime loader                                   |
| `vitest`                                                                                                     | Vite-compatible unit/integration runner             | Jest would add a second transform system                       | MIT        | Active | Dev only                                                            |
| `@testing-library/react`, `@testing-library/dom`, `@testing-library/user-event`, `@testing-library/jest-dom` | User-oriented DOM/component assertions              | Hand-written DOM harnesses are weaker and more code            | MIT        | Active | Dev only                                                            |
| `@playwright/test`                                                                                           | Controlled real-browser E2E                         | DOM emulation cannot expose native transport/CSP/browser races | Apache-2.0 | Active | Dev only; browser binary is runner-only                             |
| `axe-core`                                                                                                   | Automated accessibility rules                       | Manual checks alone are not repeatable                         | MPL-2.0    | Active | Dev only; canvas warnings do not suppress rules                     |
| `eslint`, `@eslint/js`                                                                                       | JavaScript lint policy                              | Type checking does not cover style/logic lint                  | MIT        | Active | Dev only                                                            |
| `typescript-eslint`                                                                                          | Type-aware strict lint rules                        | Untyped ESLint misses unsafe TypeScript patterns               | MIT        | Active | Dev only                                                            |
| `eslint-plugin-react-hooks`                                                                                  | React hook dependency/lifecycle rules               | Manual review is not deterministic                             | MIT        | Active | Dev only                                                            |
| `prettier`                                                                                                   | Deterministic source formatting gate                | Hand formatting is inconsistent                                | MIT        | Active | Dev only                                                            |
| `jsdom`                                                                                                      | DOM environment for fast component tests            | Running every test in Chromium is slower and less focused      | MIT        | Active | Dev only                                                            |
| `@types/node`, `@types/react`, `@types/react-dom`                                                            | Compile-time platform declarations                  | Local declarations would drift from upstream APIs              | MIT        | Active | Types only; zero runtime impact                                     |

The final production output is one 433.14 KiB raw / 123.34 KiB gzip JavaScript asset and one
11.59 KiB raw / 3.47 KiB gzip CSS asset. No optional analytics, Markdown, state-management,
component-library, icon, font or utility dependency was added.
